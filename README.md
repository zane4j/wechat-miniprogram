# 7鬼523 微信小游戏

一个基于微信小游戏原生 Canvas API 开发的纸牌小游戏项目。

## 当前版本

首个 MVP 版本包含：

- 4 人本地对局（1 名玩家 + 3 名简单机器人）
- 洗牌与发牌
- 手牌展示与选牌
- 基础出牌轮转
- 7、大小王、5、2、3 等特殊牌权重配置
- 回合结束判断
- 可扩展的规则引擎与计分接口

> “7鬼523”在不同地区可能存在规则差异。本项目暂按常见简化规则搭建，核心规则集中在 `js/rules.js`，便于后续修改。

## 目录结构

```text
.
├── game.js                 # 微信小游戏入口
├── game.json               # 小游戏配置
├── project.config.json     # 微信开发者工具配置
├── js/
│   ├── main.js             # 游戏主循环与界面
│   ├── game-engine.js      # 对局状态和回合控制
│   ├── deck.js             # 扑克牌、洗牌、发牌
│   ├── rules.js            # 牌型与大小规则
│   └── ai-player.js        # 机器人出牌策略
└── assets/                 # 后续放置图片、音效资源
```

## 本地运行

1. 下载并打开微信开发者工具。
2. 选择“小游戏”项目。
3. 导入本仓库目录。
4. AppID 可暂时使用测试号。
5. 编译运行。

## 当前简化规则

- 使用一副 54 张扑克牌。
- 4 人参与，每人发 13 张牌，剩余 2 张作为底牌。
- 当前 MVP 每次只出一张牌。
- 玩家必须出比桌面牌更大的牌；没有合适的牌时可以过牌。
- 基础特殊牌优先级：`3 < 4 < 6 < 8 < 9 < 10 < J < Q < K < A < 5 < 2 < 7 < 小王 < 大王`。
- 连续其他玩家都过牌后，最后出牌者获得新一轮出牌权。
- 最先出完手牌者获胜。

## 技术说明

当前版本刻意不依赖第三方游戏引擎，以便快速理解微信小游戏的生命周期、Canvas 绘制和触摸事件。联网版建议把权威游戏状态放在服务端，客户端只负责展示与发送操作，避免作弊和状态不一致。
